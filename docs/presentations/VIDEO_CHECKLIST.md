# Video Production Checklist
## Quick Reference for Creating Your Showcase Video

---

## 📋 Pre-Recording Setup

### **Environment**
- [ ] Quiet recording space
- [ ] Good lighting (natural or soft)
- [ ] Clean desktop (close unnecessary apps)
- [ ] Browser bookmarks hidden
- [ ] Demo data prepared

### **Technical Setup**
- [ ] Screen recording software installed
- [ ] Microphone tested (if voiceover)
- [ ] Audio levels checked
- [ ] Resolution set to 1920x1080
- [ ] Frame rate set (30fps minimum)
- [ ] Recording format: MP4

### **App Preparation**
- [ ] Backend server running
- [ ] Frontend running smoothly
- [ ] All features tested and working
- [ ] Demo queries prepared
- [ ] Map centered on Budapest
- [ ] Location access granted

### **Script Preparation**
- [ ] Script reviewed
- [ ] Key phrases memorized
- [ ] Demo flow practiced
- [ ] Timing estimated

---

## 🎥 Recording Session

### **Before Each Take**
- [ ] Deep breath
- [ ] Check audio levels
- [ ] Verify app is ready
- [ ] Start recording

### **During Recording**
- [ ] Speak clearly and confidently
- [ ] Pause between sections
- [ ] Let features load naturally
- [ ] Show UI elements clearly
- [ ] Avoid rapid clicking
- [ ] Keep mouse movements smooth

### **After Recording**
- [ ] Stop recording
- [ ] Review take (if possible)
- [ ] Note any mistakes
- [ ] Decide if retake needed

---

## ✂️ Post-Production

### **Video Editing**
- [ ] Import footage
- [ ] Cut mistakes/retakes
- [ ] Remove dead time/pauses
- [ ] Add smooth transitions
- [ ] Trim to 6-8 minutes
- [ ] Add text overlays (if needed)
- [ ] Add background music (low volume)
- [ ] Normalize audio levels

### **Visual Enhancements**
- [ ] Add intro/outro
- [ ] Include feature labels
- [ ] Add tech stack mentions
- [ ] Create engaging thumbnail
- [ ] Add end screen with CTAs

### **Final Checks**
- [ ] Video quality (1080p+)
- [ ] Audio quality (clear, no noise)
- [ ] Smooth playback
- [ ] All features shown clearly
- [ ] Professional appearance

## 🎯 Quick Tips

✅ **DO:**
- Practice demo flow before recording
- Speak naturally and confidently
- Show real functionality
- Keep it under 8 minutes
- Add captions for accessibility

❌ **DON'T:**
- Rush through features
- Use filler words excessively
- Show personal information
- Make it too long
- Skip important features

---

## 🚀 Success Metrics

Track these after publishing:
- [ ] Views (target: 100+ in first week)
- [ ] Engagement rate (likes, comments)
- [ ] Watch time (aim for 70%+ completion)
- [ ] Click-through to GitHub
- [ ] Shares/retweets
- [ ] New followers/subscribers

---

**Remember:** Quality over quantity. A well-produced 6-minute video is better than a rushed 15-minute one.

Good luck! 🎬✨
